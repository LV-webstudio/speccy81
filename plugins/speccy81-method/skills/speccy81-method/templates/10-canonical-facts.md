# Canonical facts · `00-FACTS.md`

Created BEFORE launching the first wave of agents. Everyone reads it at the start.
If an agent discovers a key datum that affects other blocks, it adds it here
(with source) and uses it; if it contradicts an existing one, it marks it `⚠ disputed` and
says so in its report. The coordinator resolves disputes.
