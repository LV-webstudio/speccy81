# Light mode · <project>

The five steps of the basic edition in a single document, for projects of 1–2 days, a single machine and low risk.
If there is personal data, money or shared production, the complete edition is needed. No golden rule is skipped: only
the paperwork is trimmed. Origin (v1.9): in a real project, a one-day extension was done this way in an hour.
