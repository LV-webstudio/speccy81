# Hiatenanalyse · «wat ontbreekt er om dit met kwaliteit te doen?»

Leidende vraag: *wat bepaalt de kwaliteit van het eindresultaat dat de klant ziet, en is dat gedekt
met concrete gegevens die een engine kan toepassen?*

Per onderwerp: zoek in `kennis/` (grep op kernwoorden) en vink af.

| Onderwerp | Zoektermen | Documenten die het dekken | Genoeg om te berekenen? | Actie |
|---|---|---|---|---|
| Hoe het werk stap voor stap wordt uitgevoerd (techniek) | | | | |
| Numerieke parameters (snelheden, tijden, afmetingen, marges) | | | | |
| Wat wel en niet te sturen is op de gereedschappen/apparatuur | | | | |
| Simulatie of validatie voordat het echt gebeurt | | | | |
| Externe omstandigheden (weer, licht, tijdstip, seizoen) | | | | |
| Veiligheid, noodgevallen en incidenten | | | | |
| Randgevallen (moeilijke omgevingen, storingen) | | | | |
| Nabewerking en oplevering (formaten, kwaliteitscontrole) | | | | |
| Automatisering van de nabewerking | | | | |
| Echte voorbeelden (bestanden, monsters) | | | | |
| Training van het team | | | | |
| Specifieke arbeids- en juridische risico's | | | | |
| **Tests met echte gegevens of echt gebruik** (is er een minimale testbank? is het al geprobeerd?) | | | | |
| **Privacy en minimale gegevens** (wat wordt gelezen, opgeslagen en verzonden; AVG) | | | | |
| **Uitrol en bestaande systemen** (waar het draait, waarmee het verbindt, wat er gebeurt als het verhuist) | | | | |

Alleen echte hiaten leiden tot een nieuw onderzoeksblok. Herhaal tot er geen belangrijke hiaten
meer zijn. Alles wat afhangt van omstandigheden (weer, licht, klantgegevens) moet
eindigen in een **selector** met regels, niet in losse tekst.
