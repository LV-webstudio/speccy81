# Speccy81-methode

![Speccy81 Method](assets/banner.jpg)

**Van idee tot lancering.** Een methode van LV-Webstudio (Speccy81) om elk project — product, dienst, module of app — met dezelfde zorgvuldigheid op te zetten: eerst onderzoeken, beslissen op basis van gegevens, wat je leert omzetten in geverifieerde kennis, die auditen, ontwerpen vóór het programmeren, in het veld testen en zonder verrassingen publiceren. Ze bestaat in twee edities, gebouwd vanuit dezelfde methode, elk als een Claude Code-pluginmarketplace.

Dit is de **basiseditie**: vrij en openbaar, met een skill, een korte gids en 8 sjablonen in elke taal.

**Languages · Idiomas:** [English](README.md) · [Español](README.es.md) · [Català](README.ca.md) · [Nederlands](README.nl.md) · [Polski](README.pl.md) · [Português](README.pt.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Deutsch](README.de.md)

## De vijf stappen

| Stap | Wat er gebeurt | Sjabloon |
|---|---|---|
| 1 · Fase 0 | Contextblad; is het project al begonnen, leg dan vast wat er al is (code, documenten, besluiten) | 01 |
| 2 | Checklist van hiaten en canonieke feiten, vóór onderzoek of ontwerp | 06, 10 |
| 3 · Fase 7 | Kort ontwerp, goedgekeurd door de gebruiker vóór het programmeren | 09 |
| 4 · Fase 8 | Bouw met echte tests en veldtests | 13 |
| 5 | Idempotent geheugen bij het afsluiten van elke stap | 15 |
| Altijd | Rekenschap met «Bewijs:» bij het afsluiten van elke opdracht; incident als een sleutel of een gegeven is blootgesteld | 21, 20 |

De fasenummers (0, 7 en 8) zijn die van de volledige methode, zodat een project kan groeien zonder iets te hernummeren. De volledige editie voegt de rest toe: fasen 1 tot 6, 8 bis en 9.

## Wat erin zit

Eén plugin per taal, elk met de skill, de gids en de 8 sjablonen: `speccy81-method` (English), `metodo-speccy81` (Español), `metode-speccy81-ca` (Català), `metodo-speccy81-pt` (Português), `methode-speccy81-fr` (Français), `metodo-speccy81-it` (Italiano), `speccy81-methode-de` (Deutsch), `speccy81-methode-nl` (Nederlands) en `metoda-speccy81-pl` (Polski).

Alle plugins bevatten dezelfde methode; installeer die in de taal van je voorkeur.

## Installatie

```
claude plugin marketplace add LV-webstudio/speccy81
claude plugin install speccy81-method@speccy81      # English
claude plugin install metodo-speccy81@speccy81      # Español
claude plugin install metode-speccy81-ca@speccy81   # Català
claude plugin install metodo-speccy81-pt@speccy81   # Português
claude plugin install methode-speccy81-fr@speccy81  # Français
claude plugin install metodo-speccy81-it@speccy81   # Italiano
claude plugin install speccy81-methode-de@speccy81  # Deutsch
claude plugin install speccy81-methode-nl@speccy81  # Nederlands
claude plugin install metoda-speccy81-pl@speccy81   # Polski
```

Vraag Claude Code daarna om "de Speccy81-methode toe te passen", ook voor een project dat al loopt. De skill laadt de gids en de sjablonen wanneer nodig.

[Wassup](https://github.com/LV-webstudio/wassup) is een optionele aanvulling wanneer meerdere machines of sessies aan hetzelfde project werken.
